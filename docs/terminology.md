# Terminology

Use these terms precisely in docs, issues, and release notes.

## Open Source

ModelPreflight's local code, tests, examples, schemas, and reference implementation are released under Apache-2.0. That is an OSI-approved open source license.

Do not describe source-available code, private services, hosted dashboards, proprietary datasets, or provider models as open source unless their licenses and required materials satisfy the relevant open source definition.

## Source-Available

Source-available means users can inspect source code, but the license does not provide full open source rights to use, modify, and redistribute. Do not use "open source" as shorthand for source-available.

## Open Weights

Open weights means model weights are downloadable or inspectable under some license. Open weights are not automatically open source AI. Avoid making open source AI claims about provider models from this project.

## Open Protocol or Open SDK

An open protocol or SDK can be implemented by others, but that does not make every related hosted service, dataset, or control plane open source.

## Benchmark

ModelPreflight runs smoke checks for prototype readiness and regression detection. It is not a formal benchmark suite, leaderboard, or model-quality authority.

## Pricing Oracle

Provider prices, free tiers, quotas, and rate limits can change without a repository update. Treat all provider pricing or availability notes as review-time hints, not current guarantees.

## Cloud Service

A hosted service may use or support ModelPreflight without becoming part of the Apache-2.0 local package. Keep local OSS claims separate from hosted service claims.
